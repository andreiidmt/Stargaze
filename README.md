# Stargaze

Website built in HTML and CSS with the objective of compiling lesser-known facts about the universe in a single place for astronomy enthusiasts.

# Description

The website covers 7 different topics, such as nebulae, Europa(Jupiter's moon) and others that I consider to be interesting for most people. Each section can be easily accessed by clicking on it's respective category on the main navigation bar. The use can also enjoy breathtaking scenery in the background.

# How to open

Because the website isn't hosted online, you will have to download the fonts and images folders and the .html and .css files. After you've placed these in the same folder, simply open the .html file with your favourite browser.
